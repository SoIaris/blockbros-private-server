### Setup
```bash
pip install -r requirements.txt

flask run
```
Alternatively, you can run this on Vercel using the `vercel.json` file.

For database hosting, you'll need to use PostgreSQL. For a free 500 MB option, I recommend [Neon](https://console.neon.tech/).

For the `VPNAPI_KEY` env, you'll need to get an API key from [vpnapi.io](https://vpnapi.io/).
